# MIJAS LTD / premium korekcija prikaza logotipa

- Sačuvan originalni vlasnikov logo i njegov prepoznatljiv plavo-narančasti znak.
- Navigacija koristi samo izvorni glavni znak i naziv (bez dva reda izuzetno sitnih opisa usluga).
- Footer i intro koriste puni logo sa svim izvornim natpisima.
- Na tamnom se koristi svijetla, kontrastna varijanta izvornog teksta; logo je proziran.
- Nema bijelih pozadina, kartica, okvira ni CSS sjena oko bijele plohe.
- Datoteke imaju nova imena i novi CSS query parametar za zaobilaženje stare predmemorije.
- Ostatak sajta (usluge, slike, intro timing, SEO demo blokada, kontakt) ostaje netaknut.
