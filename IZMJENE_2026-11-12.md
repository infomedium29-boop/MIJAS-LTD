# MIJAS LTD – ispravak mobilnog izbornika i plutajućih gumba

## Problem i uzrok
- Mobilni izbornik bio je ugniježđen unutar zaglavlja. Na zaglavlju se prilikom skrolanja koristi `backdrop-filter`, koji može postati sadržajni okvir za `position: fixed`, pa je izbornik ostajao ograničen na traku zaglavlja.
- Stari CSS bio je cacheiran do 7 dana. Novi plutajući gumbi bili su dodani u HTML prije nego što je preglednik preuzeo nova CSS pravila; zato su ikone u staroj verziji mogle biti ogromne i pojaviti se ispod footera.

## Ispravke
- Mobilni izbornik sada je zaseban susjedni element iza `<header>`; overlay je pozicioniran u odnosu na viewport. Ispravljeno je pozicioniranje pri skrolanju i zaključavanje pozadinskog skrolanja.
- Dodane su precizne dimenzije ikona i kontrole veličine plutajućih gumba. Pozivi su `tel:+385915090790`, a WhatsApp otvara `https://wa.me/385915090790`.
- Ažuriran je CSS za mobilni overlay i z-index. Dok je izbornik otvoren, plutajući gumbi su sakriveni kako ne bi prekrivali stavke izbornika.
- Dodana je verzija na CSS i JS linkovima kako Cloudflare/preglednik ne bi rabio zastarjele datoteke. Vrijeme predmemoriranja resursa smanjeno je na jedan sat.
- Bolji `aria-label` pri otvaranju i zatvaranju mobilnog izbornika.

## Provjere
- `python3 tools/deploy.py`: uspješno; izlazna mapa `dist`.
- `python3 tools/qa_static.py` i `python3 tools/qa_static.py dist`: 14 ruta bez prijavljenih neispravnih poveznica.
- Lokalni pregled s Chromium/Playwright: 320, 390, 768 i 1440 px; izbornik se otvara preko cijele visine dostupne ispod zaglavlja, uključujući nakon skrolanja; fiksne ikone imaju 52/56 px; bez horizontalnog prelijevanja.
- Vizualno potvrđeni mobilni izbornik, izgled pri skrolanju i plutajući gumbi kod footera.

## Postavljanje na Cloudflare Pages
- Framework preset: None.
- Build command: `python3 tools/deploy.py`
- Output directory: `dist`
- Nakon objave osvježiti stranicu i ponovno testirati mobilni izbornik i oba gumba. U novoj verziji CSS i JS nose `?v=20261112fix1` kako bi se izbjegla stara predmemorija.
- Demo i dalje ne otvara indeksiranje prije potvrde produkcijske domene i podataka.
- Web3Forms zahtijeva zasebno postavljanje `WEB3FORMS_ACCESS_KEY` za stvarno slanje kontaktnih upita.
